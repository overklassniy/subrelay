# cmd/subrelay

## Purpose

Application entry point. Initializes the settings, logger, engine,
state, tray, UI windows, the auto-update timer, and the GitHub release
checker, then runs the Fyne event loop until the user exits from the
tray.

## Contents

- `main.go` - Wires all subsystems together: loads settings, creates the
  engine, state manager, port planner, Fyne app, tray, UI windows, update
  timer, and release checker. Shows the first-run wizard when no
  subscription URL is configured. Wires the settings window "Check for
  updates" button and the nodes window Refresh button to their respective
  handlers. Handles clean shutdown on exit.
- `lock.go` - Platform-agnostic single-instance lock interface.
- `lock_windows.go` - Windows implementation using a named mutex
  (`Global\SubrelaySingleInstance`).
- `lock_unix.go` - Linux/Unix implementation using a file lock in the
  data directory.
- `lock_unix_flock.go` - flock syscall wrapper for the Unix lock.
- `FyneApp.toml` - Fyne application metadata (name, ID, version, icon)
  used by the `fyne package` and `fyne-cross` tools for packaging.
- `make_icon.go` - Code generator (build with `//go:build ignore`) that
  converts the tray icon PNG to a Windows .ico and compiles a .syso
  resource file embedding the icon into the executable.
- `resource.rc` - Windows resource definition referencing `icon.ico`.
- `resource.syso` - Compiled Windows resource object (generated by
  `make_icon.go` or `windres`). Regenerated per architecture by the
  CI workflow and the local build scripts.
- `icon.ico` - Windows icon file generated from the tray PNG.

## Dependencies and interactions

- Imports all `subrelay/internal/*` packages.
- Imports `fyne.io/fyne/v2/app` for the Fyne application.
- Imports `github.com/sagernet/sing-box` for the box.Options type passed
  to the engine.
- Requires CGO for the Fyne GLFW backend.
